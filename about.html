내집컷을 만든 이유

청약 특별공급에 신청하려고 알아보다가, 매번 소득분위 계산하는 게 너무 귀찮았습니다.

맞벌이인지 외벌이인지, 가구원수는 몇 명인지, 거기에 따라 적용되는 % 기준이 또 달라지고, 본인 세전 연봉을 어디서 떼야 하는지조차 헷갈리고요. 매번 청약 공고가 뜰 때마다 같은 계산을 반복하는 게 시간 낭비라고 느꼈습니다.

그래서 월급통장에 들어오는 금액(세후) 하나만 입력하면, 내가 어느 분위에 속하고 어떤 특공이 가능한지 즉시 보여주는 계산기를 만들었습니다.

기획 단계의 갈등

만들기 전에 아내랑 좀 싸웠습니다.

  • 아내: "세전·세후 다르고, 1인 가구 가산률에 성과급까지 넣어야 진짜 맞는 결과가 나오지!"
  • 저: "복잡하게 할 거면 그냥 청약홈에서 보겠지. 대략적인 바운더리 체크만 빠르게 되면 충분해."

결론은 둘 다 반영했습니다. 가산률·세전 환산·성과급 입력은 모두 들어가 있고, 동시에 슬라이더 한 번 만지면 결과가 즉시 나오는 단순함도 유지했습니다. 90%는 아내가 이긴 셈입니다.

이런 분께 추천합니다

  • 청약 특공 자격이 될지 빠르게 감 잡고 싶은 분
  • 본인 세전 연봉이 정확히 얼마인지 모르겠는 분 (대부분 그렇습니다)
  • 현재 진행 중인 청약 공고를 한눈에 보고 싶은 분
  • 맞벌이 가구 합산 소득이 어디까지 가능한지 확인하고 싶은 분

이렇게 만들었습니다

  • 실시간 청약 공고: 한국부동산원 청약홈 공식 API 연동, 마감 60일 지난 공고 자동 숨김
  • 세후 → 세전 환산: 한국 직장인 평균 공제율을 4구간으로 적용 (월소득 구간별 ×1.16~×1.28)
  • 가구원수 가산: 1인 +20%p, 2인 +10%p 자동 적용
  • 공공·민간 자동 분류: 각 단지마다 [공공]/[민간] 태그 + 본인 소득 기준 자격 ✓ ✗ 즉시 표시
  • 모바일 우선 디자인: 핸드폰으로도 한 손에 결과 확인
